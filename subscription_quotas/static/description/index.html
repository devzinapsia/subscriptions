Control de cuotas de suscripciones

Numbered installments on subscription invoices, with automatic closing after the last one

Set a maximum number of installments on a subscription and every invoice generated from it carries a legend such as "Billed installment 3 of 12". When the last installment is confirmed, the subscription is closed automatically.

Key Features

  • Opt-in per subscription: Only subscriptions with a maximum number of installments are affected.
  • Configurable legend: Any text with two %d placeholders, e.g. "Cuota %d de %d".
  • Safe counter: Moves forward only when an invoice is confirmed; deleted or cancelled drafts never consume an installment.
  • Automatic closing: The subscription closes with the "End of contract" reason once its last installment is confirmed.
  • Mid-plan start: Set the next installment to start migrated contracts where they left off.

Developed by Zinapsia for Odoo 19.
